# 《便利店怪谈》设计文档（当前版）

> 2026-11-19 定稿。本文是**唯一玩法设定**，取代旧设计文档、旧评审、旧 MVP 和旧 30 天经济模型。
> 一句话：**白天卖关东煮，18:20 进货，夜班跟鬼讲价。**
> 长版：**白天招呼街坊，夜班招呼街坊的鬼。**
> 当前阶段：**方案 v1/v2 已定，下一步做 Unity 数据、白天循环、进货、备货、夜班**；3D 场景仍暂缓。
> 60 天 / 15 小时内容骨架、周营收目标、房东惩罚、15 个店铺升级、30 条菜谱解锁见 `60天内容规划.md`。

---

## 1. 定位与边界

- **PC only**。固定柜台视角，不走路、不转视角、不做俯视、不做手机。
- 四段时间：**白天 08:00-18:00（暂定）→ 18:20 进货（卡车格子）→ 18:40-21:30 备货（白天鲜食/夜晚关键物品）→ 夜班 22:00-02:00（暂定，待确认）→ 02:00 打烊**。
- **夜班**是这家店自己的班，不是“鬼市”。旧文档里的“鬼市”一词已废弃。
- **双单夜**：一晚两个**单子**，不是两个“人”。一个单子可以是单人、情侣、一家三口。
- 差异化：三线咬合 + 便利店烟火气 + 市井智慧战胜玄学 + 验货交给白天 NPC + 账本记住活人死人。
- 白天越忙越记不住人，夜里账本把人记回来。

---

## 2. 核心循环

```
白天卖现金（含备货做的关东煮/蛋糕/便当）
  → 18:20 卡车进货：明天白天的原料/货
  → 备货：做明天白天鲜食 + 今晚夜晚关键物品
  → 夜班用库存/关键物品换阴德/故事物品
  → 阴德/物品解锁配方、供应商、故事
  → 白天卖高价/新菜 → 更多现金
```

三条硬规则：

1. **阴德不能买**，只能夜班换。
2. **夜班不能跳过**；进货可以少进，备货可以少做，但关键事件需要对应物品。
3. **账本活人死人都记**；验货是同一本账。

## 3. 白天：柜台操作

### 3.1 前期：8 个客人，全手动

- 一天约 **8 个客人**；不能均匀来，要排 **两个高峰**（2-3 个挤在 90 秒里），三选一才有压力。
- 每位客人 **3-5 件货**；货品在柜台上以随机角度出现，玩家**左/右转 15° 或直接拖动**，把**条形码转到下方、对准扫描区**，对准后才能点**扫码**；逐件扫完点**收款**。
- 没对准不能扫；扫错/漏扫要自己补。收完一位再接下一位；**不是一键接待**。
- 8 个客人里留 **1-2 个伏笔/熟客**，别全是路人。
- 高峰三选一：**排队收银 / 关东煮 / 补货**，只能做一件。
- 平淡期留给补货、定价、整理；不走路，货架是点选面板。

### 3.2 中期：自助扫码机

- **4 个简单单**自动结账；**6 个复杂单**手动；另有 **屏幕外背景客流 10-15 单**（算营业额，不需要逐个操作）。
- 自助机不是“免费收入”：每次有 **10-15% 异常**（年龄、重量、支付、未识别），玩家点 1-2 下处理；忽略会流失/退款。
- 复杂单要有真正的判断：限购、价格不符、分单、退换、易碎装袋，不是“件数更多”。
- 中期三选一：**手动复杂单 / 自助机报警 / 关东煮**。
- 柜台留给熟客/特殊客，自助机跑匿名客流。

### 3.3 后期：生鲜

- **6 个生鲜单**手动（宰鱼切肉）+ **6 个自动单** + 背景客流。
- 生鲜是瓶颈；后期一天约 **12-15 分钟**。
- 后期三选一：**生鲜 / 自助机报警 / 关东煮**。
- 生鲜切割必须能被自助机报警打断：手上停刀、鱼等着、客人耐心掉。

### 3.4 操作细节

- 找零：选面额组合，不逐枚拖。
- 装袋：大单触发一次，不做每单物理摆放。
- 上架：点选，不走路。
- 常规客也要摆正条形码再扫码；特殊客（伏笔/富哥/熟客/鬼客）才手动 + 对话。
- 员工、排班、货架布局、热力图、促销、差评系统不进当前 MVP。

### 3.5 白天鲜食（备货做的）

- **关东煮**：萝卜/鱼丸/豆腐等放进锅的 3 个槽位，凑齐后下锅；6-10 串；白天卖；夜晚 warm；**不做 timing，不会失败**。
- **蛋糕**：和面 + 调 + 烤；基底+甜味+口味 tag 匹配，第一次成功解锁配方；白天卖；夜晚 sweet。
- **便当**：米饭 + 鱼/肉/蛋；用切肉右块/边角料；白天卖；夜晚 memory/最后一餐。
- 这些是可选上限：不做也能卖包装货；做了提高客单价，也覆盖夜班通用请求。
- 特殊白天客：道士/殡葬店/当铺/老太太，每 6-8 天来一个；具体见 5.2。

## 4. 生鲜切肉

- 屏幕出现一块不规则鱼/肉，标**总重量**；顾客说**目标重量**（例：要 2.4kg，整块 6.9kg）。
- 玩家根据面积判断，**一刀切**；左边卖给顾客，右边留着继续卖给后面的客人。
- **10 秒内**操作完；一刀定生死，不修。
- 评分按 `误差 = |左块实际 - 目标| / 目标`：

| 误差 | 结果 |
|---|---|
| ≤1% | 精准，+5% 售价 |
| 1%-10% | 原价 |
| 10%-50% | 失误，价格从 95% 线性掉到 80% |
| >50% | 失败，顾客不要；**只废左块，右块保留** |

- 1% 在 2.4kg 上是 24g；UI 要给刻度/网格/放大，不然是运气不是技术。10% 原价是主目标，1% 是精通奖励。
- 剩下的右块和边角料进关东煮/员工餐/灵异料理，别让“切坏”只剩惩罚。
- 这是 **2D overlay**，不改 3D 场景；不规则多边形 + 一刀 + 面积算重量。

## 5. 18:20 进货与备货

### 5.1 进货：只有格子卡车

- 供应商卡车停后门；玩家把货**装进卡车车厢格**，没有第二层背包。
- 前期车厢只开放一部分：**5x4=20 格**；中期 **6x5=30**；后期 **8x6=48 + 冷藏区 4x2**。
- 前期只有小店的一部分；中后期随着自助机/生鲜台/采购量，供应商给更多格。
- 商品按箱/捆/盘：泡面箱 2x2、饮料 2x3、关东煮盘 2x1、冰棍 1x1、香糯米 1x2、鲜鱼/鲜肉 2x2 且必须冷藏。
- 玩家拖/转/塞；塞不下就少带，第二天缺货少赚，不硬失败；有“按昨日订单自动摆”保底，手动摆得好给空间/折扣奖励。
- 经济不变：进货现金 = 次日 COGS；参考订单 208/480/675 都能塞进对应车厢。
- 不做深夜批发市场地图；不走路。

### 5.2 备货：白天货 + 夜晚货

- 18:20 进货之后、夜班之前；**3-5 分钟**；做一个白天货 + 一个夜晚货，不要求全做。
- **白天货（原料来自卡车）**：
  - **关东煮**：萝卜/鱼丸/豆腐等放进 3 个锅槽，凑齐后下锅；6-10 串；白天卖；夜晚 warm；不做 timing。
  - **蛋糕**：和面 + 调 + 烤；基底+甜味+口味 tag 匹配，第一次成功解锁配方（旷野之息式，不要求精确配比）；白天卖；夜晚 sweet。
  - **便当**：米饭 + 鱼/肉/蛋；用切肉右块/边角料；白天卖；夜晚 memory/最后一餐。
- **夜晚货（原料来自夜晚/事件）**：
  - **招魂蜡烛**：肋骨/石蜡/模具；研磨/拌/倒/脱；寻人鬼；道士买。
  - **引路香**：阴米/香灰/黄纸；烧了强制/提高故事鬼；道士买。
  - **阴米糕**：阴米/糖/香灰；饥饿鬼；老太太也买。
  - 后续：纸人（替死鬼/殡葬店）、骨铃（寻仇鬼/当铺）、还魂汤/往生符（故事）。
- 关键物品是**特定事件的钥匙**，不是通用货币；可以卖鬼客换阴德，但事件里更多。
- 夜晚事件：寻人鬼/迷路鬼/饥饿鬼/替死鬼/寻仇鬼/最后一餐/生日鬼；给对应物品推进/挡灾，不给就等下一晚/断故事。
- 特殊白天客：道士（蜡烛/引路香）、殡葬店（纸人）、当铺（骨铃）、老太太（阴米糕）；每 6-8 天来一个，不同天。
- 底层复用：卡车/抽屉共用 GridContainer；切肉/脱模/研磨/搅拌共用 GestureCheck；2D overlay，不改 3D 场景。
- 详细配方/价格/时间见 `数值方案_便利店怪谈.md` 的「备货」节；菜谱线索/关东煮串串见 `菜谱线索_关东煮.md`。Demo 已接品类→线索→试做，关东煮按具体串名产出（海风萝卜串 x6 等）。

## 6. 夜班与顾客池

### 6.1 夜班节奏

- 一般一晚 **1 个单子**；每隔约 3 天变成 **2 个单子**（双单夜）。
- 一个单子可以是单人/情侣/一家；不叫“双人夜”。
- 1 单夜是日常，2 单夜是事件夜；2 单夜可以做“故事单 + 随机单”，也可以两个故事单。
- 通用单用白天货/关东煮；特定单要关键物品（招魂蜡烛/引路香/阴米糕/纸人/骨铃），见 5.2。

### 6.2 顾客池

- 普通单和故事首位顾客在**同一个池**，权重不同。
- 故事首位出现后，这条故事的**后续顾客加入池**等待抽取。
- 允许多个故事同时发生；**同时最多 3 条活跃故事线**。
- **2 天**没有故事客人 → 故事权重增加（软保底）。
- **3 天**没出任何故事 → 强制出一条故事（优先活跃故事下一位；没有就放一个新故事首位）。
- **4 天**某条活跃故事没出现 → 强制出“等得最久”的那条；**优先于 3 天保底**。
- 4 天保底的是“等得最久的那一条”，不是三条都必出。三条都饿、一晚 2 单时，先出最久的两条，第三条顺延到 5 天。
- 新故事首位只在活跃 <3 时进池；否则抽到会变 4 条。
- 只有 **ready** 的故事进池和保底；等玩家动作/道具的故事标“暂停”。三条都暂停时 3 天保底兑现不了，账本提示玩家推进/放弃一条。

### 6.3 拒单

- **拒单 = 剪线**：故事中断/进分支；后续客人**不再进池**；活跃位释放。
- 4 天保底对这条线自然失效（不是重置，也不是被刷掉）。
- 3 天全局计数因为这次“出现过”会重置；玩家最多再等 3 天见下一条故事。这是拒单的代价，不能靠拒单刷 4 天保底。
- 拒绝前给一次确认：“这条故事线会中断，后续客人不再出现。”
- 账本标“中断”；抽屉里的故事物品**保留**，作为未完成凭证。
- 分支可以埋 flag、物品、结局，但不要再往顾客池里加客人；真要后续，就当一条新故事线重新抽，仍受 3 条活跃上限约束。

## 7. 故事线与资源

### 7.1 故事线示例（数值可改）

- **第 1 天**：有人寄存一个招财符，售价 30 年阳寿。
- **第 3 天**：一个披头散发的人领着小孩子来，要卖孩子的阳寿，换自己的荣华富贵。玩家可以选择接不接受。
  - 接受：获得“70 年阳寿”和“孩童魂魄”，卖出招财符。
- **第 6 天**：第 1 天的鬼客来取走 30 年阳寿；玩家自己留有 40 年阳寿和“孩童魂魄”。
- **之后**：获得还魂符后，可以复活孩子，作为店员；小店员为了争取阳寿在店里打工。

### 7.2 资源

> 夜班货币统一叫**阴德**；旧文档写作“香火”，是同一个东西。

| 资源 | 来源 | 用途 | 说明 |
|---|---|---|---|
| 现金 | 白天卖货 | 进货、房租 | 硬通货 |
| 阴德 | 夜班帮鬼客 | 配方、供应商、故事 | 不能买，只能换 |
| 阳寿 | 故事线专用 | 故事选择/复活/结局 | 剥鬼的代价，不是通用货币 |
| 故事物品 | 夜班故事 | 抽屉/后续故事 | 放在抽屉，不进白天背包 |

- **阴德 = 帮鬼；阳寿 = 剥鬼**。两套道德账，玩家自己选。
- 小孩是剥鬼的后果，也是赎罪；复活后成为店员，可真的顶岗位（自助机/看锅/装袋），用叙事解决后期“6 生鲜 + 6 自动”的劳动力瓶颈。

### 7.3 抽屉

- 柜台下的小抽屉，**D2 风格网格**；故事物品占不同大小格子（符 1x2、魂魄 1x1、盒子 2x2）。
- **不是背包管理**：容量宽/可扩，不做容量惩罚；玩家摆它是为了收集感和手感。
- 每个故事线有专用物品；中断的故事物品保留。
- 与白天背包分开：白天背包是货，抽屉是故事。

### 7.4 账本

- 一本账，三个页签：**待验 / 夜班 / 常客**。
- 第二天熟客一句话验货；玩家把这句话记进待验格。
- 验货不是鉴定 UI，是账本里多一句话。
- 账本同时是怪谈档案和常客名册；主题：**这家店替人记事**。

## 8. 数值原则

- **可执行数值**见 [数值方案_便利店怪谈.md](数值方案_便利店怪谈.md) 和 `数值方案_便利店怪谈.xlsx`；本节只留原则。
- 旧 30 天经济模型/xlsx 已作废，不要参考。
- 只做方向：
  - 前期 8 个手动，日营业约 300-500。
  - 中期自助机 + 背景客流，日营业约 800-1,000。
  - 后期生鲜 + 自助，日营业约 1,200-1,500。
  - 这是**阶梯**，不是 2% 平滑增长。
- 先统一口径：人/天、客单价、毛利率、净利、服务时间、到达率。
- **阴德**按**鬼客数**算，不按营业额百分比：30 天约 40 单 ×8 = 320；夜班商店支出 200；结余约 120。
- 备货/道士/特殊白天客是**可选上限**，30 天基线（320/800/1350-1450，现金 508/1257/7222，阴德 320/200/120）不动；备货收益另算。
