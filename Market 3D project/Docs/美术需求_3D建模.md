## 0. 一页版（先给美术看）

- **风格**：低多边形、简化材质、强灯光氛围；2000 年代中国街边便利店；黄昏/雨夜/深夜；安静、微微不对劲，但不血腥、不 jump scare、不二次元大眼。
- **镜头**：PC 固定柜台，不是第一人称自由走。相机高 1.55m、竖 FOV 55°、距玻璃约 3m；店内天花板 2.95m。**镜头 0-4m 内是精模区，4m 外降细节，街对面只做剪影。**
- **规模**：60 天经营，但 3D 场景是**一个店 + 一段街**，不做开放世界；靠灯光/时间/小道具复用。
- **P0 先做**：店内壳（地/墙/顶/窗/门）、收银台、货架、冷柜、**关东煮机**、POS/扫码枪/收银抽屉、15-20 个商品、2 个顾客、街景 blockout、5 个氛围道具。
- **预算**：整场景 **150k-220k tris**，Draw Call <300；主角道具 4-15k tris，普通商品 80-300 tris，角色 4-8k tris。
- **贴图**：PBR，2K 主角/1K 道具/512 小物；贴图集优先；不烘焙灯光到 Albedo；发光牌/灯管/屏幕给 Emission。
- **交付**：`.blend/.max` 源文件 + FBX + PNG/TGA 贴图 + Unity 材质/预制体 + 一个 `ArtTest` 测试场景；命名规范见第 3 节。
- **不要做**：真实品牌 Logo、版权包装、写实 3A 级细节、URP/HDRP 材质、把文字做成模型、碰撞体/灯光/相机/脚本塞进 FBX。

## 1. 美术方向

### 1.1 一句话

**一家开在旧街拐角的夜班便利店：店内是暖白的日光灯和彩色商品，店外是湿漉漉的落日/深夜街道。平时只是有点旧，夜深后才发现有些客人不太对。**

### 1.2 风格关键词

- 低多边形 / 平直色块 / 轻手绘纹理 / 简化材质。
- 2000 年代中国街边小店，不是日式精致便利店，也不是赛博朋克。
- 黄昏、雨夜、深夜三套光照；湿沥青、玻璃反光、暖色灯管。
- 安静、空旷、微微 liminal；超自然元素克制（蜡烛、香、纸人、旧账本），**不恐怖血腥**。
- 固定镜头，轮廓和色块优先；不追求近距离写实。

### 1.3 不要的方向

- 不要二次元大眼萌系角色；不要 Q 版三头身。
- 不要 3A 写实皮肤/布料/毛发；不要 4K 贴图堆满。
- 不要真实品牌（Lawson/7-11/统一/康师傅等）的 Logo、包装、店招。
- 不要用模型做中文文字；文字交给 Unity TMP/World Space Text。
- 不要做血腥、尸体、惊吓 jump scare；超自然是“不对劲”，不是恐怖片。

### 1.4 色彩

| 区域 | 主色 | 辅色 | 备注 |
|---|---|---|---|
| 店内 | 暖白/奶油 `#F2E4C8` | 灯管黄 `#FFE3A3`、货架灰蓝 `#6F7C8A` | 不要纯白，旧店的脏暖 |
| 商品 | 高饱和红/蓝/黄/绿 | 白/米色包装 | 固定镜头下靠颜色区分品类 |
| 黄昏街道 | 橘 `#FF8A3D`、洋红 `#C94B7A` | 深紫 `#2B1B3D` | 湿地面拉长反光 |
| 深夜 | 深蓝 `#0B1730` | 路灯琥珀 `#FFB45A`、月光冷白 | 店面暖光从玻璃溢出 |
| 超自然 | 冷白/青灰 | 烛火橙、香灰灰 | 不要荧光绿/紫色魔法光 |

## 3. 技术规范

### 3.1 引擎/导入

- Unity 2023.1.12f1，**Built-in**，Linear。
- FBX 2020/2022；1 Unity unit = 1m；Y-up；模型正面朝 +Z。
- 应用变换：位置/旋转/缩放全部归零；**不要负缩放**。
- Pivot：落地物在底部中心；门在铰链；抽屉在滑轨；锅盖/柜门在转轴；商品在底部中心。
- 不在 FBX 里放：灯光、相机、碰撞体、脚本、空节点堆、隐藏高模。
- 模型不烘焙光照/AO 到 Albedo；需要 AO 单独贴图或顶点色。

### 3.2 面数/性能预算

| 类别 | 目标 tris | 说明 |
|---|---:|---|
| 整场景 | 150k-220k | 不含角色动画/特效 |
| 收银台组合 | 10k-15k | 台体+抽屉+POS+扫码枪 |
| 关东煮机 | 4k-6k | 含锅格、签子、盖子、汤面 |
| POS/收银机 | 1k-2k | 屏幕用发光面 |
| 货架 bay | 800-1,500 | 可实例化 |
| 冷柜 | 1.5k-3k | 玻璃单独 |
| 普通商品 | 80-300 | 盒子为主，不要倒角过度 |
| 角色 | 4k-8k | 2 LOD；固定镜头看上半身 |
| 鬼客 | 2k-4k | 半透明/剪影，不做过细 |
| 街景建筑 | 1k-3k/栋 | 剪影+发光窗 |
| 小道具 | 100-500 | 烟灰缸/杯子/伞/垃圾袋 |

- Draw Call <300；重复商品/货架用同一材质/贴图集，支持 GPU Instancing。
- 主角/角色 2 级 LOD；商品/小物可无 LOD；背景建筑 2 级。
- 不要用高模 + 法线贴图硬撑；低模轮廓优先。

### 3.3 贴图/材质

- PBR：Albedo / Normal / Metallic-Smoothness（或 Mask）/ Emission。
- 尺寸：主角 2K；普通道具 1K；小物 512；整组贴图集 2K；招牌/大面积 2K，不建议 4K。
- sRGB 用于 Albedo/Emission；Normal/金属粗糙用 Linear。
- 材质数：单个资产 1-3 个；整场景尽量 <40 个材质。
- 玻璃单独材质（透明/半透明），湿地面/瓷砖按现有 shader 的 UV 做。
- 发光：灯管、招牌、POS 屏、冷柜灯、路灯罩、蜡烛/香头。**给 Emission 颜色/强度参数**，不要只画亮。
- 不要用 URP/HDRP 专属 shader；Built-in Standard 或现有 `Market3D/Shaders` 兼容。
- 文字/Logo 不烘进贴图；用占位色块/空白标签，Unity 里换 TMP。

### 3.4 命名/目录

```
Assets/ArtPack/
  Models/
    Architecture/    SM_Store_Floor_A.fbx
    Counter/         SM_Counter_Base_A.fbx, SM_OdenMachine.fbx
    Shelves/         SM_Shelf_Bay_A.fbx
    Products/        SM_Product_Noodle_A.fbx
    Characters/      SK_Customer_Base.fbx
    Props/           SM_Prop_Candle.fbx
    Street/          SM_Street_Lamp.fbx
  Textures/
  Materials/
  Prefabs/
  Animations/
  Source/            .blend / .max
  ArtTest.unity      测试场景（不要用 Market.unity）
```

- 前缀：`SM_` 静态模型、`SK_` 骨骼角色、`M_` 材质、`T_` 贴图、`P_` 预制体、`A_` 动画。
- 命名用英文/拼音，不要中文路径；版本后缀 `_A/_B`。

### 3.5 动画

- 角色：Humanoid rig，原地动画（in-place），30fps。
- 必需：idle、walk、pay/递钱、receive/接东西、leave；鬼客：float/idle、dissolve。
- 道具：门开/关、冷柜门、关东煮锅盖、收银抽屉、扫码枪抬起、收据打印（可用简单位移）。
- 动画命名：`A_Customer_Idle`、`A_Ghost_Float`、`A_Oden_LidOpen`。
- 不要求战斗/跑跳；固定柜台，动作幅度小。

## 5. 光照/材质验收

- 三个时段都要看：`DAY 14:00`、`DUSK 18:20`、`STARRY NIGHT 23:00`。
- 店内不能死黑；商品颜色在暖光下仍可区分；玻璃外街景不能过曝。
- 发光材质在黄昏/夜晚要亮，但白天不能像霓虹灯。
- 湿地面/玻璃反射由现有 shader 处理；美术只需正确 UV/网格，不烘焙反射。
- 固定镜头 1920×1080 截图验收；不要只转视角看单个模型。

## 6. 交付与里程碑

### 6.1 交付物

1. **灰盒/blockout**：先按尺寸搭白模，确认镜头/比例/构图。
2. 最终 FBX + 贴图 + 材质 + 预制体。

4. `ArtTest.unity` 测试场景（用 P0 资产搭一遍，不要改 `Market.unity`）。
5. 一张 1920×1080 三时段截图/接触表。
6. 资产清单（名称/面数/贴图/材质/碰撞/动画）。

### 6.2 建议里程碑

| 阶段 | 内容 | 时间（1 人） |
